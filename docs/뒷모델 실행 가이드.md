# 뒷모델 실행 가이드

일반화 질문·SQL 32쌍으로 뒷모델을 학습하고, 생성된 GGUF에 질문을 입력해 예측 SQL을 확인한다. 아래 명령은 저장소 루트에서 PowerShell로 실행한다.

각 작업에서는 ‘또는’으로 연결된 두 명령 중 하나만 실행한다. `python back.py`는 저장소의 `.venv`가 있으면 그 환경의 Python을 사용하고, 없으면 `back.py`를 호출한 Python을 사용한다. 모든 상대 경로는 저장소 루트 기준이다.

## 1. 실행 환경과 옵션 파일 준비

프로젝트에 가상환경이 없으면 `python -m venv .venv`로 생성한 뒤 의존성을 설치한다.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

아래 명령은 저장소에 포함된 두 옵션 파일을 사용한다. 값을 직접 지정할 때는 원하는 항목만 수정한다. [뒷모델 옵션 가이드](<./뒷모델 옵션 가이드.md>)

| 예시 경로 | 역할 |
| --- | --- |
| [data/example/sql_types.json](../data/example/sql_types.json) | 데이터셋에 포함할 SQL 유형과 예시 비율을 정한다. |
| [data/example/train.json](../data/example/train.json) | 모델 구조와 학습 방법을 정한다. |

## 2. 데이터셋 생성과 분할

먼저 원본 질문·SQL 쌍을 생성한다.

```powershell
# 원본 데이터셋 생성
.\.venv\Scripts\python.exe -m src.data_generation.generalized_pairs.generate --count 32 --sql-types data/example/sql_types.json --seed 42 --output data/example/generated/v1_dataset.json
# 또는 다음으로 실행
python back.py generate --count 32 --sql-types data/example/sql_types.json --seed 42 --output data/example/generated/v1_dataset.json
```

원본을 학습셋과 검증셋으로 분할한다.

```powershell
# 학습셋과 검증셋 분할
.\.venv\Scripts\python.exe -m src.data_generation.build_back --input data/example/generated/v1_dataset.json --seed 42 --validation-ratio 0.05
# 또는 다음으로 실행
python back.py build --input data/example/generated/v1_dataset.json --seed 42 --validation-ratio 0.05
```

분할 결과인 `v1_dataset_back_train.json`과 `v1_dataset_back_validation.json`은 원본 `v1_dataset.json`과 같은 폴더에 저장된다.

## 3. 학습

```powershell
# 뒷모델 학습
.\.venv\Scripts\python.exe -m training.back.train --config data/example/train.json --train-file data/example/generated/v1_dataset_back_train.json --run-dir runs/back --seed 42 --device cpu
# 또는 다음으로 실행
python back.py train --config data/example/train.json --train-file data/example/generated/v1_dataset_back_train.json --run-dir runs/back --seed 42 --device cpu
```

새 실험에는 기존 학습 기록이 없는 폴더를 사용한다. 예시의 `runs/back`에는 검증 성능이 가장 좋은 `best.pt`, 재개용 `last.pt`, 학습 기록 `history.jsonl`이 저장된다.

## 4. GGUF로 내보내기

```powershell
# 체크포인트를 GGUF로 내보내기
.\.venv\Scripts\python.exe -m training.back.export_gguf --checkpoint runs/back/best.pt --output models/example/back.gguf
# 또는 다음으로 실행
python back.py export --checkpoint runs/back/best.pt --output models/example/back.gguf
```

## 5. GGUF로 추론

질문 하나를 입력하면 예측 SQL이 터미널에 출력된다.

```powershell
# 질문 한 개로 추론
.\.venv\Scripts\python.exe -m inference.back --model models/example/back.gguf --device cpu --question "retrieve {*} from <TABLE1>."
# 또는 다음으로 실행
python back.py infer --model models/example/back.gguf --device cpu --question "retrieve {*} from <TABLE1>."
```

여러 질문을 처리할 때는 검증 파일을 질문 목록으로 사용할 수 있다. 결과 JSON에는 입력 순서대로 원래 질문(`input`)과 예측 SQL(`output`)이 저장된다.

```powershell
# JSON 파일의 질문으로 추론
.\.venv\Scripts\python.exe -m inference.back --model models/example/back.gguf --device cpu --input data/example/generated/v1_dataset_back_validation.json --output data/example/generated/predictions.json
# 또는 다음으로 실행
python back.py infer --model models/example/back.gguf --device cpu --input data/example/generated/v1_dataset_back_validation.json --output data/example/generated/predictions.json
```

저장된 결과를 확인한다.

```powershell
Get-Content -Raw -Encoding UTF8 -LiteralPath data/example/generated/predictions.json
```

## 독립 평가 (선택)

별도로 준비한 질문·정답 SQL을 `data/example/back_test.json`에 저장했다면 다음 명령으로 학습한 체크포인트를 채점한다.

```powershell
# 독립 평가셋 채점
.\.venv\Scripts\python.exe -m training.back.evaluate --checkpoint runs/back/best.pt --data data/example/back_test.json --device cpu
# 또는 다음으로 실행
python back.py evaluate --checkpoint runs/back/best.pt --data data/example/back_test.json --device cpu
```
